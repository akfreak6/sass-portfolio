# scss-portfolio
Personal portfolio site built with HTML, SCSS, and vanilla JavaScript.

[Live Site](https://akfreak6.github.io/sass-portfolio/dist)

## Running Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)

### Setup

1. Clone the repository
   ```bash
   git clone https://github.com/akfreak6/sass-portfolio.git
   cd sass-portfolio
   ```

2. Compile SCSS to CSS
   ```bash
   npx sass scss/main.scss scss/main.css
   ```

3. Open `dist/index.html` in your browser

### Development

To watch for SCSS changes and recompile automatically:
```bash
npx sass --watch scss/main.scss scss/main.css
```

## Tech Stack

- HTML5
- SCSS/Sass
- JavaScript (vanilla)
- Font Awesome (icons)
- Google Fonts (Inter)
